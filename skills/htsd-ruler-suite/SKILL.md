# 四尺套装（交付件自检与投箱勾验）

**尺子自己先证明自己没坏**——先跑 `scripts/ruler_suite_check.py`（12 条断言，含 7 条反例），全过再用尺子量业务数据。

**本 skill 与 `handoff-box-verify` 插件互补**：插件把两把尺子做成了 MCP 工具（可在会话里直调）；本 skill 提供**脱离插件也能用**的脚本版四尺 ＋ 统一自检入口。

---

## 第 0 步：先问对主体与口径（最高杠杆）

量数之前先锁死四件事：**验的是什么件／它由谁提交／依据哪一版／按哪条口径**。不确认就动手，验的可能是错的题。

- **侧车口径**：团队现行 = **33B 纯单行**（32 位 md5 ＋ 换行）。**值同但尺寸不合 ⇒ 不合规**。
- **"存在"≠"合规"≠"可交"**：三件事分开判，禁合并成一个"没问题"。
- **分母动态算出**：件数 × 应投箱数 = 应投格，**不写死**；不虚报零命中。

## 四把尺子一览

| 尺子 | 干什么 | 入参 | 出参 / 失败信号 |
|:--|:--|:--|:--|
| `sidecar_verify.sh` | 逐件正卷 md5 vs 侧车 md5，拦截 **空壳／不等／抄旧值** 三型 | 目录绝对路径 | stdout 比对报告；**exit 0=全等 / 1=任一异常** |
| `box_matrix.py` | 件 × 箱勾验表（**逐格 md5**），空格与不等清单 | `--papers` `--boxes` `--targets` `--out` | stdout JSON；**exit 0=应投格全 ✅ / 1=有空格或异常** |
| `roll_matrix.py` | 应得矩阵（人头 × 场次）＋ 空格清单，**禁以扫盘代盯人** | `--roster` `--papers` `--out` | stdout JSON；**exit 0=无空格 / 1=有缺卷或缺侧车** |
| `exam_dir_check.sh` | 答卷目录 **存在性／可写性／探针** 三合一 | 目录绝对路径 | stdout 三项状态；**exit 0=全过 / 1=存在或可写不及格** |

### 何时用哪把

- **交件前**：`sidecar_verify.sh` 逐件验侧车 → `box_matrix.py` 验投递落位。
- **盯人头**（谁没交、谁缺侧车）：`roll_matrix.py`，**按人点名，不按目录扫**。
- **开考/开箱前**：`exam_dir_check.sh`，先把目录存在性与可写性坐实。
- **交付后自查**：四把全跑 ＋ `ruler_suite_check.py` 自检。

## 自检：尺子自己先证明自己没坏

```bash
python3 scripts/ruler_suite_check.py --scripts ./scripts --out ./自检.json
```

**12 条断言 = 5 正例 ＋ 7 反例**，在临时沙盘里自建 fixture 后**真跑四脚本**再断言：

| 断言 | 类型 | 期望 |
|:--|:--:|:--|
| R1 | 正例 | sidecar_verify 计数自洽：全等2＋不等1＋缺失1＋空壳1 == 总数5（尺子自己的分母断言） |
| R2 | **反例** | 侧车抄旧值（值断链）⇒ 必须报「不等」且 exit=1 |
| R3 | **反例** | 缺侧车 ⇒ 必须报「侧车缺失」 |
| R4 | **反例** | 空壳侧车 ⇒ 必须报「侧车空壳」 |
| R5 | **反例** | 值同但 48B 含名型 ⇒ 按 33B 团队口径**判不合规**（尺寸维度独立判） |
| R6 | 正例 | 目录存在且可写 ⇒ 存在性/可写性双 PASS ＋ exit=0 |
| R7 | **反例** | 目录不存在 ⇒ 存在性 FAIL ＋ exit=1 |
| R8 | 正例 | 件在「箱名/日期/件名」三层结构内 ⇒ gaps=0、publishable=True |
| R9 | **反例** | 件不在箱内 ⇒ gaps≥1、publishable=False（**不虚报零命中**） |
| R10 | 正例 | 分母断言：cells == papers × targets（动态算出） |
| R11 | **反例** | 1 人交齐 1 人缺卷 ⇒ gap_count=1、expected=2 |
| R12 | 正例 | 全部交齐 ⇒ gap_count=0、exit=0 |

**反例的意义**：反例断言的是「**尺子该报错时必须报错**」。尺子拦不住＝尺子失灵（FAIL），不是数据问题。**反例全过才准用尺子下结论。**

## 侧车四条纪律

1. **值＋尺寸双验**：同时验「侧车值 == 实物 `md5 -q`」与「侧车字节 == 33」。**只验尺寸等于没验**（尺寸对、值是旧的＝断链）；只验值会漏格式。
2. **先改实物，后写侧车**：反序 ⇒ 侧车立即断链（等于给旧值发新证）。
3. **同名件必比内容版本**：值同值只证明侧车没撒谎，**不证明它描述的是当前在用的那版**。
4. **归正不覆盖旧值证据**：断链侧车另存 `*.md5.stale_<日期>_值断链留痕`，**不删、不原地覆盖**。

## 投箱三判据（缺一不算交）

| 判据 | 含义 |
|:--|:--|
| **ADDR_OK** | 每个应投箱每一格都命中件（含日期层） |
| **BAD=0** | 空格 ＋ 不等 ＋ 侧车异常 合计为 0 |
| **分母断言 PASS** | 应投格 == 件数 × 应投箱数（动态算出，不写死） |

**投箱面 ≠ 本区凭据面**：投箱成功**不等于**本区侧车已落。**正文落盘 ＋ 侧车同值回算 ＋ 投箱三动作都完成**才算交。

---

## 报告纪律

- 报「全部在／无问题」前，**全局 find ＋ 双路径交叉印证**；
- 报「总件/命中/空格/不等」**四个数**，并**声明分母口径**；
- **尺子报错先分诊**：「尺子坏了（该看见的看不见／算错）」vs「我调错了（参数口径不对）」——**处理方式相反**；
- **尺子返回"少"时先找活位在哪**：投递箱有活位与嵌套旧副本，看错根目录会**凭空指控同事漏投**；
- **空结果不等于事实成立**，换方法复验。

---

## 反模式（踩过就别再踩）

- ❌ 只验侧车字节数就宣布"侧车合规"；
- ❌ 先写侧车后改实物；
- ❌ 把「逐件报告行」当「总评汇总行」抓数（**尺子的尺子也会坏**——解析断言时先切汇总段）；
- ❌ 断言里取错变量（首跑结果 vs 二跑结果）——**我调错了 ≠ 尺子坏了**；
- ❌ 投递箱看卷根就判"缺箱"——**先全局 find 找活位**；
- ❌ 报"0 命中"而不说分母。

---

## 边界

- 只读本机盘，**不跨机、不改他人既有件**；
- 断链件**报冲突不自行归正**（除非显式 `force=true`）；
- 落盘矩阵 md 的侧车由 `box_matrix --out_sidecar` 处理，但**落盘件本身仍需独立复算**；
- 本 skill **不占用** Skill 资产登记表 #9 `dispatch-triple-check` 槽位（派单三重校验，成员E名下）。

### 首跑逮到的两个真 bug（尺子的尺子也会坏）

1. **断言解析错**：v0.1 的 `grab()` 在全文里抓关键词，抓到的是**逐件报告行**（`✅ [答卷_…] 全等 (md5=…)`）而不是**总评汇总行**（`✅ 全等：2`）⇒ 4 条断言被自己的解析错判成 FAIL。
   **修法**：只切 `=== 总评` 之后的汇总段再取数。
2. **断言取错变量**：R12 误取首跑的 `j`（gap=1）而非二跑的 `j2`（gap=0）。
   **性质**：这是「**我调错了尺子**」，不是「尺子坏了」——两者处理方式相反。

> 这两条已写进 SKILL.md 的「反模式」段。**尺子报错先分诊**，是本 skill 的第一纪律。
