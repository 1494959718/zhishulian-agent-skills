# 算力底座降本决策器（技能库保管人 自研 v1.0 · 2026-10-22）

**为什么需要它**：算力底座的选型争论，最后都会变成一句"到底哪个便宜"。但只比单价会得出错误答案——**本地自建的真正优势不是单价，是边际成本趋零＋数据不出域＋交付工期可控**；而它的真实代价是**一次性投入**和**交付工期**。本 skill 把这三项一次算清，并给出 skill/插件/MCP 降本抓手能吃下的比例区间。

**归属**：工业化电影级内容生产系统·算力底座项目组（研发线：成员B 主责用 skill/插件/MCP 做降本创新）｜公司技能/工具库 保管人：技能库保管人

## 快速开始

```bash
# 小批量（先看清 API 是否更省）
python3 compute_cost_model.py --clips 200 --seconds 5 --tier 720p --iterations 3

# 大批量（看本地自建的临界点与工期）
python3 compute_cost_model.py --clips 2000 --seconds 5 --tier 1080p --iterations 2

# 机器可读（供其他工具/MCP 消费）
python3 compute_cost_model.py --clips 2000 --tier 1080p --json

# 换机型/换报价：外置参数表覆盖，不改代码
python3 compute_cost_model.py --clips 800 --params my_params.json
```

参数： `--clips` 片段数｜`--seconds` 单片段秒｜`--tier 720p|1080p`｜`--iterations` 平均迭代倍数｜`--model Wan2.2|HunyuanVideo1.5|LTXVideo13B`｜`--hw` 本地硬件档位｜`--params` 外置参数表｜`--json` 机器可读输出

## 输出怎么读（三条线，别只看一条）

| 路线 | 一次性投入 | 边际成本 | 真实优势 |
|:--|:--:|:--:|:--|
| **本地自建** | 高（卡价） | **≈0**（仅电费） | 数据不出域；边际成本趋零；可无限次迭代 |
| **Replicate / fal** | 0 | 按 5s 计价 | 无运维；冷启动快；可弹性扩容 |
| **结论口径** | — | — | **纯比钱本地未必赢**；本地赢在**批量规模 + 工期可控 + 数据合规** |

**关键判读**：看两条线——
1. **盈亏平衡片段数**（对**最优 API** 计算，不是对 Replicate）→ 低于此量走 API，高于此量本地更省。
2. **本地交付工期**（片段数×迭代×单片段分钟 ÷ 每日有效渲染小时）→ **工期撞上线就必须混用**：草稿/迭代层本地 LTX，出片层云端 Wan/Hunyuan。**只算钱不算工期＝算错。**

## 降本抓手（skill/插件/MCP 化路径，本 skill 内置五条）

| 抓手 | 可吃下比例（口径区间） | 落地形态 | 算式 |
|:--|:--:|:--|:--|
| 资产一次生成·多处复用 | 0.20–0.45 | 插件（派生任务队列）＋MCP（资产索引检索） | 宣传片/社媒切片/预告版从分镜母版派生 → 独立渲染需求减少 |
| 量化＋小模型路由 | 0.05–0.15 | skill（路由规则）＋工具（量化权重管理） | INT8/INT4 降显存→同机并批；草稿层 LTX、出片层 Wan |
| 批量调度＋结果缓存去重 | 0.05–0.20 | MCP（渲染队列与缓存命中统计） | 同 seed/prompt/参数命中缓存即复用；批量排队避免空转 |
| 分层质检（小模型初筛＋人工终审） | 0.05–0.20 | skill（质检判据集）＋插件（批处理钩子） | 自动判据（闪烁/穿帮/字幕/时长）先过，人工只看初筛命中件 |
| 分层共享底座（内部口径） | 0.10–0.30 | 自研 MCP（服务编排） | 底层 Transformer 共享／高层分支独立 → 多风格多分支不重复载权重 |

⚠ **比例是工程口径区间，不是承诺值**；落地前须按真实管线标定。**区间上界＝可全部吃下的部分**，各抓手不叠加。

## 纪律（沿用团队现行铁律）

1. **每个价格/时长有来源位与取证日**，写在参数表 `meta` 里；换报价走 `--params` 覆盖，**不改代码、不改口径**。

3. **输出带算式**：盈亏平衡、边际成本、工期都打印算式，可复算。
4. **证据级 B**（可复核二手：厂商公开报价页与第三方横评）；**采购前须以实际报价单复算**，不可拿本表当合同价。
